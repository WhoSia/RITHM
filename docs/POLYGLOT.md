# Polyglot language-role ledger

This implements the [Cross-Lab Polyglot Computation Atlas](https://app.notion.com/p/3e9ef561cf9281008219e330bcce1b55): select a language for a *distinct runtime, data, control or verification boundary*, not for language count.

- **Python 3.11+**, stdlib: canonical original Study 1 CSV interpretation, single-person choices → joint group states → deterministic social-payoff decomposition, explicit source hash.
- **Base R 4.4+**: independent data parser and group payoff/variance checks, not a duplicate authority for a human causal claim.
- **CSV/JSON**: external source protocol and machine-readable analysis, not a programming-language quota.
- **GitHub Actions YAML**: read-only CI, no bot commits, raw data or scientific score uploads.
- **Markdown/Notion**: explain the mechanism conjecture, estimand and limits.
- **Historical, not active**: Stata original author scripts; SUMO/XML and Bash/python S02 engines. Both live in the preserved legacy Git/Drive archive.

Cross-language approval here means *two implementations agree on the same payoff arithmetic*, not two independent human experiments. Session-level treatment assignment must be authenticated before inferential or causal claims.
