## Policy clock and competing models

- Stage A chooses A–B versus A–C before observing the CURRENT incident. Stage C chooses C–B versus C–D, conditional on A–C; CURRENT incident is visible at C ONLY in the information treatment. Previous experienced traffic is observable after past rounds in both arms. Treatment order differs across sessions.
- S0: regime/order/time, previous public route counts and incident; L: own previous route/streak; F: within-treatment smoothed previous personal route frequency (includes last choice); F−1: smoothed personal route frequency up to t−2 ONLY, to separate older history from last choice; E: experienced own and relative cost; P: deterministic different named peer's prior group choice, an imperfect negative control.
- Six **session-heldout**, not person-random folds; standard-scaled logistic regression C=1, no grid tuning. Candidate models exploit previous OBSERVED actions in heldout sessions (one-step teacher-forced), not a fully simulated policy trajectory.

## Proper pre-incident forecast (P4), not an after-shock score

Original S2 verifies **all 24 group×treatment 20-round sequences have exactly 4 incidents**. At round t with k previous accidents:
`Pr(Z_t=1 | past)= (4−k)/(21−t)`.
Compute group expected cost under z=0 and z=1 using valid information timing, then average BEFORE seeing the current shock. Score against realized source route-count group cost; F−1+L pre-incident MAE 12.68130 versus S0 12.80750. Former P1–P3 conditional **realized** shock evaluation had F−1+L MAE 9.66138 and S0 9.77335; these are DIFFERENT estimands and must never be interchanged. On t≥2, simple last-group-occupancy plus shock prior baseline MAE 18.96510, an untuned weak comparator. F+L+E pre-incident cost MAE 12.88616, a preserved negative result.

**Serious macro ceiling:** independent-person path projection omits route-choice covariances entering quadratic group costs. It also extrapolates a C-branch choice response learned only on actual A–C entrants to hypothetical upstream A–B entrants. Thus group predictions are sensitivity diagnostics under untested assumptions, NOT identified collective response or an admissible counterfactual treatment effect. P1–P2 source discrepancy in six group-rounds retained unchanged; historical raw-Cost means differ from published source-flow means.

## Exact scientific verdict and successor

- **PASS:** distinct older-revealed-history and previous-action PREDICTIVE contributions, no upstream current-shock leakage, fixed 4-of-20 clock, 27/27 local source/clock regression tests.
- **HOLD:** causal habit versus endogenous stable preference; C-stage nonentrant counterfactual; within-group response dependence; prospective alternative-guidance welfare improvement; novelty beyond classical dynamic discrete-choice/state-dependence and traffic information theory.
- **P5:** frozen individual random-intercept or partial-pooling rival, cold-start test; session-heldout group covariance correction and route externality gradient; negative effects retained.
- **Reproduce:** obtain the cited S2 XLSX separately, then run the P3 and P4 scripts and associated 27-case tests in the chat research package. No raw participant data, binaries, or new GitHub Actions generated by this documentation commit.

RITHM-2.6 OPEN. Scientific endpoints are route-choice history, two-stage actual incident timing, and group congestion welfare, not research-administration workload.
