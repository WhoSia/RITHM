## A simple proposed regime selector can fail

A source-wide synchrony-gated alternative compares lag5/lag10 past observed loss across the same links over prior **24 bins (2 hours)**; if ratio exceeds **1.2**, switch all links to lag10 for current 5-min source target. It uses no current or future observation, triggers for **5.31%** of source test observations, and yields source MAE **19.05165→18.51525** (2.815% better) on **14,537,369** matched source records, but only **10/41 weeks** favor it. July–December advantage **0.323%**, excluding five March–April anomalous weeks just **0.134%**. Nine after-the-fact thresholds/periods (12/24/36 bins ×1.2/1.5/2.0) were examined; none is prospectively confirmed on a new untouched cohort. Thus anomaly detection and broad forecasting improvements are separate.
