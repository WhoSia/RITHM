# Interpretation boundary: selection and dependence
Same 24 sessions used for previous model discovery, so scores are exploratory even though lambda/lapse are trained only on other sessions. Comparing q=1..9 and selecting the best q using all held-out losses introduces winner-selection bias. A future design should use nested whole-session CV, with outer test session never used for candidate selection. Within-session six-person outcomes are dependent through congestion. Rows are not independent replications; cluster uncertainty at session or experimental group. Different q values may fit better without identifying personal memory capacity.
