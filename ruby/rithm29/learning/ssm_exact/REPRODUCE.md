# Reproducible exact SSM study
The complete locally executed analysis, fold parameters, and all 34,560-row q1..9 held-out prediction matrix are delivered in `RITHM29_SSM_Exact_Q1to9_20261031.zip` in the current ChatGPT conversation. Use the author original `data_task_all_switch_230705.csv` from the authenticated Drive RITHM source archive. The standalone `engine.py` and `test_engine.py` are committed here for independent testing; run `python test_engine.py` with NumPy and SciPy. Full data pipeline additionally requires pandas and scikit-learn. Original authors' experiment is not copied to the public code repository.
