# No post-choice information leakage
The actor's time-t forecast reads only own prior actions and obtained payoffs. Informed subjects additionally have past observed group route counts, allowing unilateral-deviation foregone payoff reconstruction with opponents held fixed. Uninformed subjects cannot read actual past total A counts, travel values or realized congestion costs, even if the researcher CSV exposes them. At t=1 both strategy payoff histories are empty, probability 0.5. In a partial-feedback state when only one route has been tried, report probability 0.5 until both routes have a valid history. Each newly observed payoff is appended *after* predicting that period's own action.
