# Personalized q_i: sequence likelihood remains distinct
The uniform q=1..9 mixture currently averages per-period P(y_it|q) over uniform prior and independently at each t. If q_i is fixed for player i, the correct full-history marginal likelihood is (1/9) sum_q product_t P(y_it|q,H_i,t-1), NOT product_t ((1/9) sum_q P(y_it|q,H_i,t-1)). With lapse, replace each term by (1-eta)P+eta/2. Posterior weights update from prior observed participant choices. Each person's choices are strategically coupled to others; the likelihood is conditional on observed group histories, not a generative joint equilibrium likelihood. Do not compare in-sample fitted latent q to out-of-session tested EWA as if on equal footing.
