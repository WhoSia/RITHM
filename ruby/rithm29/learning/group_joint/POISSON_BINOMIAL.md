# From six individual probabilities to route count probabilities
Given conditional-on-history independent Bernoulli choices with P(A_i)=p_i, the probability generating function of N_A is G(z)=product_{i=1}^6[(1-p_i)+p_i z]. Its coefficients give the seven possible counts by successive polynomial convolution. This independence assumption is a *hypothesis*, not entailed by individually calibrated p_i. For each source group-period, we computed count logloss, seven-category Brier, count MAE and expected congestion cost C(N)=4+0.5(N-4)^2. Scores are conditional one-step assessments, NOT multi-period freely generated trajectories. True joint correlation/common signals can break independence.
