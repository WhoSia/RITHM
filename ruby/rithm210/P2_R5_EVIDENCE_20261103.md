# RITHM-2.10 P2-R5 — Longitudinal actor history, nested fold checks, and latent shock robustness
Research date: 2026-11-03. Evidence status: independent local Ruby original-source execution; public GitHub implementation published; exact published GitHub SHA/remote Actions run not yet verified.

## 1. What the original participants' identity structure actually permits
From the author-approved [Noussair–Qiao raw ZIP in Drive](https://drive.google.com/file/d/1M3m0kCSEJ-FJfkx4g2dtcaro8MO7ZmsE/view), `data_task_all_switch_230705.csv` SHA-256 `d36520564b60ba5281e7b571d2ecfd94e055b9ab7f78bd4e9eaf762844d0f8bb`, filtering trt1-3, excluding session 2/101 and Period 1-39:
- 24 sessions, 5,616 group transition observations, 33,696 individual transitions.
- 288 distinct (session,ID) participants, each **117** period observations: 39 periods in each section 2,3,4.
- 48 distinct (session,Group) groups of six; **all 48 retain exactly the same six ID members across sections**. There are 4 one-group sessions, 16 two-group sessions and 4 three-group sessions.
- IDs should only be compared within session; no person linkage across distinct sessions is inferred.

The group identity is fixed while the information treatment changes across the three sections. This permits a genuine repeated-measures behavioral prediction design, but does not separately identify enduring traits, treatment effects or order/carryover effects.

## 2. Strictly past-only actor online state
Base switch probability `p_base(i,t)` is fitted from only the 20 sessions outside the heldout sixth fold, keyed by treatment, informed status, own previous route and own experienced cost, with alpha 20 shrinkage. For heldout actor i in current section, use their prior choices from periods **less than** t only: k prior switches in n prior observed decisions. Update
`p_online(i,t) = (strength*p_base(i,t) + k)/(strength+n)`.
This is a predictive adaptive shrinkage heuristic, **not** a validated psychological generative mechanism. After scoring period t, update k and n with observed switch at t; the current outcome never enters its own forecast. Group probabilities result from analyst convolution of all six actors' individual Bernoulli forecasts, not a claim that any one uninformed player observed all six histories. Group-level current and next occupancy are not passed into the individual probability function.

The `within_section` variant resets histories when section changes; the `cross_section` variant continues using previous sections from the same (session,ID). `strength` in {5,20,80} is a regularization hyperparameter, not a measured cognitive resource price.

## 4. Nested strength selection by session
Outer 6fold with 4 heldout sessions in each fold. For each outer train set of 20 sessions, inner 5fold CV uses 16 fitting / 4 validation sessions. Only inner past actor periods update history, and validation outcomes are not used to fit base global probabilities. Choose separately for (a) joint and (b) count logloss from strength 5,20,80.
- All six outer folds chose **within-section strength20 for joint**, **strength80 for count**.
- Pooled outer joint baseline **1.980980331567275**, selected **1.9351158650213764**; delta **−0.045864466545899**.
- Pooled outer count baseline **1.3999243859120258**, selected **1.394907890671779**; delta **−0.005016495240247**.
- These are two **separate metric-targeted rules**, not one common generative distribution jointly optimized on both.
- Nested CV removes direct outer-fold strength-selection leakage, but candidate model family and grid have been shaped by earlier investigations of these same data: not independent prospective validation.

## 5. Frozen shared group shock after online actor history
With within-section strength20 held fixed, reintroduce earlier common logit shock ±gamma with gamma in {0, .15, .30, .45}, without re-selecting gamma on heldout data. Original source sixfold:
- Gamma 0: joint **1.9351158650**, count **1.4049850581**.
- Gamma .15: joint **1.9352058538**, count **1.4051721311**.
- Gamma .30: joint **1.9369242447**, count **1.4060032869**.
- Gamma .45: joint **1.9435824577**, count **1.4081366260**.
Gamma .30 joint delta (vs zero) **+0.00180838**, 20,000 whole-session bootstrap exploratory 95% **[−0.00027560,+0.00371831]**, only 6 of 24 sessions improve. Gamma .45 worsens joint by +0.00846659, CI [+0.00430377,+0.01230112].
Contrast with earlier P2-R3 where gamma .30 improved marginal joint prediction slightly BEFORE individual online-history adaptation. This supports investigation of **actor history as a competing source of formerly unexplained joint structure**, but does not rule out different latent-shock models and does not identify participant psychology.
