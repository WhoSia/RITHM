# RITHM-2.10 · P3-R52 — Sharp dynamic welfare bounds from frozen incomplete histories

2026-11-21 KST · R49–R51 six-seat synthetic, no new participants

## 1. Why R51's first-switch identification is not a welfare result

R51 already has a counterexample: 14 allocated synthetic groups, 12 post-second-round signed assignments, two groups with no assigned arm, and a complete-case first-switch contrast of +1. Under all feasible missing first outcomes its rate contrast instead lies in [−1/3,+1/3]; both ends were attained by completing the same frozen SQLite prefixes through the actual state machine. The published R51 roster anonymizes live study keys and excludes receipt tokens.

Our independent R51 registry/upper-envelope audit initially used a raw study identifier and consequently posed an avoidable disclosure risk. R51 cross-check now hashes it using the existing group_ref algorithm and explicitly checks the signed arm, incomplete prefixes and ledger consistency. The former “complete-case” label was also corrected: partially recorded groups may nevertheless have known first outcomes. The original R51 first-switch checker is the canonical report; the second checker is an independent conservative cross-check, not a competing truth source. In particular, the first-checker uses the frozen future clock to know that a group scheduled no focal revision even when the group stops early.

A known first switch does not identify the following 40-round congestion path. R51's initial no-assumption resource-cost interval treats each unobserved period's excess congestion as any value between 0 and 48, independently. That is safe but ignores the central protocol restriction: **only the one specified seat can revise in each round**.

## 2. Frozen-clock dynamic programming

An event prefix determines a six-bit actual route state `m` and a remaining seat clock `s_t,...,s_H`. At each unobserved round the scheduled seat can keep its route or flip it, and nobody else can move. For any next mask `m'`, the end-of-round excess cost is

`g(m') = 3 (popcount(m') - 4)^2`, obtained from the original experiment's total cost `C(n)=24+3(n-4)^2`.

Define `V^min_t(m)` as the minimum remaining excess congestion cost from t to H over all physically permissible unobserved choices. Set `V^min_{H+1}(m)=0`, and compute

`V^min_t(m) = min_{b in {0,1}} [g(m XOR (b << s_t)) + V^min_{t+1}(m XOR (b << s_t))]`.

Replace min by max for `V^max`. For the model-specific resource metric, each round costs `2g(m') + 1{focal seat switches}` in *half-point units*, with the same two-action recurrence. The complete and partial observed costs are added to the continuation bounds. This is an exact finite-state Bellman enumeration, a standard method rather than a claim of a newly discovered general theorem. It makes no assumption about learning, obedience, rational choice or response to ±4.

**Sharpness in the free-action completion class:** backward induction considers precisely both legal actions at every remaining step. Every computed minimizer/maximizer is therefore attained by a complete sequence preserving the entire frozen prefix and the assigned seat clock. The implementation constructs four explicit witness paths (min/max excess congestion, min/max total resource cost) and tests them by independent forward replay. At most `64(H+1)` mask-time states are needed.

## 3. Concrete completed-prefix calculation

Start at 5:1. After both recorded initial rounds, all seats have stayed at 5:1; observed excess congestion is 3+3=6. The remaining three scheduled seats are `[0,2,3]`, all initially A, and seat 0 is the designated focal seat.

| Analysis for the 5-round allocation | Lower excess congestion | Upper excess congestion | Width |
|---|---:|---:|---:|
| Old R51 broad 0–48-per-future-round envelope | 6 | 150 | 144 |
| R52 frozen-clock reachable 6-mask paths | **6** | **21** | **15** |

The lower witness switches seat 0 to B at round 3 and keeps the efficient 4:2 occupancy afterward. The upper witness switches each scheduled A seat to B; occupancy evolves 5→4→3→2 and the extra congestion totals 0+3+12 after the first two rounds. In the R49 half-point total-resource metric, the exact range is **[13,43]**: excess congestion contributes twice its score, plus one unit for each focal switch. These are **integer-valued synthetic welfare bounds**, not a behavioral effect estimate or physical monetary valuation.

For a different frozen schedule `[2,3,4]` with no post-settlement focal opportunity, the excess congestion bounds remain [6,21], whereas the minimum total cost is 12 half-points because a non-focal A seat can correct the occupancy without a focal switching event. Thus occupancy-congestion bounds alone need not determine switching-resource bounds.

## 4. Engineering and falsification gates

- R52 auditor reads the existing R51 pseudonymous operator registry and re-audits every event prefix before dynamic programming. The resulting interval must be contained in the earlier conservative R51 48-per-remaining-round envelope. No participant identifiers or original human rows are published.
- The test enumerates all 2^3 legal completions for **three independently frozen seat clocks**, confirms the DP's min/max against brute force, and checks each returned witness by a separate forward replay. A complete group must produce exactly one cost value equal to the R49 original outcome, with no remaining uncertainty.
- The existing R51 first-choice bound remains [−1/3,+1/3] in its worked example. Narrowing the range for costs does not imply the first-choice effect becomes identified, and vice versa.
- CI now separates the independent R49–R52 Python job from the legacy Ruby research job. Historical Ruby and Python failures were diagnosed through actual GitHub Actions logs: R18 used a non-existent `Audit.occ`, historical Python tests depended on a deliberately retired `rithm20.py`, R22 used invalid `*.025` Ruby literals, and the welfare probability calculator retained impossible zero-mass bins. Each has a minimal repair on `WhoSia` commits; later remote jobs must be checked before stating the entire pipeline passes.
- The 2024 SSRN revision of Zeng et al. (SSRN 4908072, 41 pages) remains the current information-design working text. This R52 finite-state proof does not depend on identifying Zeng's 2026 publisher edition.

## 5. Research decision

The next mainline question is no longer whether an incomplete participant record can be assigned a single trajectory estimate—it cannot without extra assumptions. It is how much of a **macro welfare effect** remains identified after using only legally accessible information and the actual revision clock. On real historical source sessions, there is no randomized R49 signed treatment, so the new R52 interval must NOT be retrospectively presented as a causal estimate. A future retrospective exercise can apply the same finite-state conditional reachability to authorized historical trajectories, while keeping the original author's public-information filtration intact.
