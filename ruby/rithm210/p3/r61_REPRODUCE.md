# R61 original-data and source-free reproduction boundary

1. **Source-free tests (safe on public CI):** from the directory holding R61 and the sibling R54/R59/R60 modules, run `python -m unittest discover -s . -p 'test_r61_*.py' -v` with Python 3.11 or newer. No external packages required.
2. **Original source:** requires a separately authorized, private Noussair–Qiao original ZIP. Do not distribute it. Exact 1,192,207 bytes SHA-256 `e6adce2da4d1c01455e912aa15144f192108394cbec0bd7f767e2732dcec9953`. The in-memory R54 audit rejects altered bytes before any person rows are read. The `r59_prior_exposure.py` source parser inherits the original 24-session restrictions.
3. **Original-data regeneration:** `python r61_run.py /private/approved_original.zip /existing/output/directory --only r61_results.json` (replace file name with any of the eight approved output names). Execute one scenario at a time so that the 40-period stochastic simulations do not exceed tool-runtime limits. Only the selected aggregate JSON is written. Private IDs and trajectories remain RAM-only. The output directory must already exist; a source hash failure produces no output.
4. **Folds:** 24 outer whole-session holdouts; 23 inner session folds with 22-session base fits, a frozen `[0,2,4,8,16,32,64,inf]` discount grid, and no tuning with the outer heldout session. Dynamic choice input at target t is only observed choices strictly before t. No human current-period route occupancy is provided to an uninformed actor.
5. **Independent scenario:** `r61_closed_loop.py` generates all target section t≥2 routes and individual switch records itself, with identical pseudo-random uniform arrays across rival models. It does not read original target outcomes after t1 except in the **scoring** stage. Predecision value/payoff is not used as a predictor in R61; no new external reward or future hidden Value can leak.
6. **Original aggregate files:** `r61_results.json` (actor / joint next-interval), `r61_identity_null.json` (blocked actor relabel), `r61_subgroups.json` (information, route, segment), `r61_three_segment_results.json` (binary synthetic exact witness plus 288 actor-triple correlations), `r61_rollout_observed.json`, `r61_rollout_fair.json`, `r61_rollout_seed2.json`, `r61_macro_diagnostics.json` (only 96-group aggregate occupancy and stability).
7. **Archive:** `python r61_build_archive.py` deterministically creates a ZIP containing only source-free Python, unit tests, aggregate outputs and this report. Check the inner per-member SHA256 manifest and external ZIP SHA256; NEVER include the restricted original ZIP, raw `data_task*` CSV, exact individual routes or Value tape.
8. **Boundaries:** no causal mechanism, policy efficacy, actual switch-cost price κ, hidden trait identification or out-of-dataset confirmatory replication is claimed. All cluster bootstrap intervals are descriptive and all tasks are based on one repeatedly examined experimental cohort.
