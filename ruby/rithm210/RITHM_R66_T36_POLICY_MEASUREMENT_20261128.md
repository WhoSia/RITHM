## 2. Exact policy-class closure and counterexamples
Common state cost c, finite actions with row-stochastic kernels P_a. For open-loop schedules, define K=span{1,P_word c for all finite words including empty}. Compute by repeated rank expansion of an independent frontier until invariant under all action kernels. For matched alternate kernels Q_a, equality of all finite open-loop schedule accumulated costs, all starting states, iff (P_a-Q_a) annihilates K for each action. Necessity: subtract each prefix schedule's accumulated costs from its one-step extension to obtain equal products applied to c; prefix by a and subtract. Sufficiency by product induction. Feedback policies allow kernels with each row chosen separately from available action kernels. Their span is generated by one base policy plus single-row substitutions: every row-selected kernel is the base plus a sum of individual row changes. Close K under those generators; equality on K for each action row is equivalent to equality for all state-feedback schedules. This is finite-state linear algebra related to value equivalence; no broad theorem priority claim. General history-dependent policy not covered.

Counterexample A, c=(0,0,0,1), deterministic destinations in state order 0..3. P_a=(1,0,0,3), Q_a=(2,0,0,3), P_b=Q_b=(0,3,2,3). Each constant action has identical all-state all-horizon values between models; schedule a,b starting at 0 has total costs 1 vs 0. Counterexample B replace b by (0,3,3,3). All open-loop sequences agree, but feedback choosing b in state1 and a in state2 at second decision yields 1 vs 0. Open-loop closure dimension3, feedback4. Tested closure against all 81 row-selected policies for 30 randomized four-state action families.
