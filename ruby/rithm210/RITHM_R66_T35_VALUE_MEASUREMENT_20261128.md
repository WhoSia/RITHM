## A. All-state all-horizon criterion
For finite row-stochastic P0 and P with common known state cost c, define V_H(P)=sum_{k=0}^{H-1} P^k c, with H including initial state cost. Define K=span{1,c,P0 c,P0² c,...}. For every starting state, V_H(P)=V_H(P0) for every H>=1 iff (P-P0)v=0 for all v in K. Necessity: subtract successive horizons to obtain P^k c=P0^k c; apply P to the common sequence. Sufficiency: induction; equality on K and invariance under P0 suffice. Include 1 because stochastic rows automatically preserve it; iterate exact rank until first dependency, since P0 maps previous generators to their successors and P0 1=1. Dimension <= number of states. Finite horizon prefix equality for all H<=h uses k=0..h-2, not necessarily a single terminal horizon or a single initial state. If each admissible matrix shares this criterion, arbitrary time-dependent sequences of them (and statewise row reselection) preserve every value vector by backward induction. No claim that fixed and dynamic robust extrema always coincide when values vary.

For an uncertain probability row q with measured A q (including normalization), known reference transition and target vector rows B spanning K, the number of independent additional unrestricted linear measurements needed to determine B q on the original fiber is rank([A;B])-rank(A), provided affine hull of feasible fiber is q0+ker A (e.g. a positive feasible row in the simplex with only equality constraints). Necessity: adding fewer independent rows leaves a direction in ker A not annihilated by B; use sufficiently small opposite perturbations. Sufficiency: extend row span by independent B rows. For more constrained/boundary fibers use actual affine direction space; feasible discrete sensors, measurement error and unknown reference model require separate design. Rank deficit is local to specified row/fiber and targets, not a sampling guarantee. T7's moment-degree condition is the earlier Boolean special case. This is established linear algebra/value equivalence adapted to a measurement question; no general mathematical priority claim.

## B. Exact reset-model measurement
Use T33 states m=0..5, c_m=3(1-m)^2, row0 q (exchangeable count law), other rows reset to 0 with probability r else stay. r=1/20; p=7/160, t=p²; q reference independent binomial. With e0 indicator of no switches, P c=(1-r)c+r c0*1+(q·c-c0)e0; P e0=r*1+(q0-r)e0. Thus K=span{1,c,e0} if q·c != c0 (as here). Cost c quadratic; measured mass, E M and E[M(M-1)] determine q·c. The single extra measurement q0=P(M=0) determines every horizon value, and is necessary over the positive pair-moment fiber since e0 not in degree<=2 polynomial span. Deficits by raw moment degree d=0..5 are [2,2,1,1,1,0]; adding q0 to degree2 gives zero. Even degree4 alone is insufficient for this positive fiber. Exact alternative q+10^-6*(0,1,-3,3,-1,0) is nonnegative, preserves first and second moments and q0, differs in full distribution, and passes value equivalence at H1/2/3/10/40. Induction proves all horizons. Other reset rules, heterogeneous state rows, unobserved cost, or unknown policy transport can require other information; do not use this result as a universal measurement prescription.
