## Exact theorem: even group-level negative controls cannot resolve local shock versus direct dependence
Let group g contain a previous-A users and b=6-a previous-B users. A fair hidden Z_g independently assigned for each group induces person-level switching probabilities p+delta*Z_g. Given Z_g every person switches independently, with no direct strategic response. Then mean-centered residual products satisfy:
within group E[(U_g-bp)(D_g-ap)] = a*b*delta^2,
between independent groups E[(U_g-bp)(D_h-ap)] = 0 for g != h.
At a=b=3,p=1/2,delta=3/40 these are 81/1600 and 0 exactly.
A structurally directed rival samples U_g from the *same marginal* then D_g from P_L(D_g|U_g). Its full joint P(U_g,D_g) and full distribution across independently generated groups are identical to the latent model, yet do(U) changes D only in the directed model. Thus between-group negative control alone cannot distinguish these mechanisms. This construction is not a theory of actual temporal causation in a simultaneous-choice experiment.

## Fixed-gamma group-specific common logit shock: whole distribution versus one moment
For each group let unobserved fair Z_g shift all personal switch logits by +/-gamma; conditional switches independent. For the same 5,148 eligible within-vs-other comparisons, observed within-minus-between residual cross moment = +0.03494872602504185.
Because mixture shifts personal marginal means, the predicted between-group cross residual centered at the *original independent baseline probabilities* is NOT strictly zero. It equals the product of each independent group's mixture-induced mean bias. This was initially omitted, then explicitly corrected in [commit f567e634](https://github.com/WhoSia/RITHM/commit/f567e6349e49e05c9e9b0a1a6946c99fb5340702).
At gamma=.30: predicted within +0.0204337173; predicted between +0.0000645349; predicted excess +0.0203691823; observed minus predicted +0.0145795437. Exploratory session-cluster 4000-draw percentile 95% interval [-0.0107181136,+0.0377587472].
At gamma=.40: predicted within +0.0362955755; between +0.0002011085; excess +0.0360944670; observed minus predicted -0.0011457410, interval [-0.0264276375,+0.0220962045]. No evidence of a uniquely true latent group shock; gamma .4 was considered AFTER seeing the data.

## P2-R3 nested hyperparameter experiment (new)
Outer sixfold = sorted-session ID mod6. For each outer holdout of four sessions, leave all outer outcomes unseen. On remaining 20 sessions, inner fivefold of four sessions per fold; fit actor Markov with 16 inner-training sessions and calculate inner validation joint logloss for grid gamma={0,.15,.30,.40,.45,.60}. Select gamma minimizing weighted inner validation joint logloss. Refit actor Markov to 20 outer-training sessions and evaluate on four untouched outer sessions. Inner and outer folds are session-disjoint; each outer fold has 819,819,1053,1053,936,936 grouped transitions respectively. Ruby actual original-source run: **all 6 outer folds choose gamma=.30**, pooled outer heldout joint logloss selected **1.9785483256** versus gamma=0 baseline **1.9809803316** (difference **-0.0024320059**). Next-A count logloss selected **1.4001826198** versus baseline **1.3999243859** (difference **+0.0002582339**, worse). Nested selection itself did not use heldout outcomes; however the candidate model, smoothing alpha and grid arose after earlier exploration on this SAME dataset, so this is NOT prospective confirmation nor independent external validation. Existing session bootstrap for gamma=.30 vs 0 joint loss had exploratory interval crossing zero. Avoid overstating this stability.
